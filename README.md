# Life Debt（命债）

一个 Fabric 模组：**向死亡借命，用债务喂养世界的敌意。**

签下命债，你便能在致命一击下不死——代价是每借一次命，债务就攀高一分。债台越高，世界越不容你：先是缠身的粒子，接着是夜里循迹而来的追债者，最终整个世界都在向你讨债。你选择的**契约**，决定你以什么姿态偿还这笔债。

> 这是 `1.2.0` 起的重构方向。旧的「可食用图腾 + 命债增益 + 生命上限偿还」机制（1.x）已被下方的「契约 + 债务等级」框架取代。

## 核心循环

```
使用死神债券 → 自愿签订契约（消耗一枚图腾，获得借命容量 + 常驻增益）
      │
      ▼
受到致命伤 → 还有容量？── 是 → 借命抵死（回满血，容量−1，债务+1）
      │                          │
      否                         ▼
      │                  债务累积 → 跨越阈值 → 债务等级提升
      ▼                          │
   正常死亡              ┌───────┴───────┐
                        ▼               ▼
              世界影响加剧          契约增益放大
        （粒子 → 追债者 → 世界异常）（负债越深、力量越强）
```

- **签约完全自愿**：开局赠送一张**死神债券**（丢失自动补发）与一枚不死图腾。使用债券随时打开契约面板；签约消耗一枚图腾。不签约也能正常游戏，仅承受 2.5 颗心的生命上限压力，没有任何打扰。
- **借命抵死**：拥有容量时受到致命伤不会死亡，而是回满血、容量 −1、债务 +1。容量耗尽后，命债不再介入，玩家正常死亡。
- **债台高筑**：债务按阈值推导出**债务等级**，可在债务祭坛用债券或图腾偿还。
- **世界追债**：债务等级越高，世界对你的敌意越强。

## 契约（Contract）

契约不是 Buff，而是你的玩法方向——决定借命的代价与偿还的姿态。首批三种：

| 契约 | 定位 | 常驻收益 | 借命效果与代价 |
|---|---|---|---|
| **血契** | 狂战 | 生命越低，伤害与攻速越高 | 借命获得力量，但额外累积债务。 |
| **魂契** | 法师 | 经验获取 +25% | 借命时按「经验 → 债券 → 耐久」支付，换取护盾再生并抵销该次债务。 |
| **亡契** | 逃亡 | 常驻移速 +10% | 借命时瞬移隐身无敌脱身，但被追债的概率翻倍。 |

契约增益随**债务等级**放大（正常 ×1.0，每级 +0.2，死人未亡 ×1.8）——负债越深、力量越强，还不还债是玩家自己的策略取舍。

## 债务等级（Debt Level）

债务等级由当前债务值派生（不单独存储，避免失同步）。跨越阈值即解锁对应的世界影响：

| 等级 | 债务阈值 | 世界影响 |
|---|---|---|
| 正常 | `0` | 无。 |
| 借命者 | `≥ 2` | 缠身粒子效果。 |
| 负债者 | `≥ 5` | 夜晚生成「追债者」。 |
| 亡命者 | `≥ 7` | 世界出现异常（村民涨价等）。 |
| 死人未亡 | `≥ 10` | 触发终极世界事件。 |

## 支持的版本

本模组仅支持 **Minecraft 1.21.11**，不再维护旧版本。

加载器：Fabric Loader `>=0.19.3`。需要 Fabric API。
